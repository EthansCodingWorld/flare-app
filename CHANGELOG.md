# Changelog

## v0.1.0 — Initial Release

- OBS folder watcher with automatic clip detection
- Social media-style clip feed with search and sorting
- Tagging system with add/remove
- Discord integration — share clips directly to your server
- Auto-update system with background checks
- SQLite local database (no cloud required)
- Thumbnail generation via ffmpeg
- Cross-platform: Windows, macOS, Linux
